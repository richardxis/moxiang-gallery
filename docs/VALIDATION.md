# 测试

## 执行

```powershell
cd backend
mvn '-Dtest=*BoundaryTest' package
```

```powershell
cd frontend
npm run build
```

## 覆盖范围

- 用户与空间：登录检查、团队角色、越权、成员变更和额度更新。
- 图片：上传校验、属性处理、审核、元数据、版本与清理任务。
- 缓存：条件规范化、分页隔离、命中、共享版本、TTL 和故障回退。
- 协作：租约、续租、退出、重连状态、过期版本与保存幂等。
- 分析：范围互斥、聚合、逻辑删除、标签去重、大小分段与排行。
- 图片搜索：三步响应解析、验证页跳转、异常、链接校验、颜色排序与阈值。
- 批量编辑：权限、同空间限制、逐图版本、命名规则、整批提交和失败回滚。

SQL 回归使用隔离的 H2 MySQL 模式。真实 MySQL 的分析对照需要显式指定自己的私有配置：

```powershell
mvn '-Dtest=SpaceAnalyzeMySqlReadOnlyTest' '-Dmoxiang.analysis.mysql.config=配置文件完整路径' test
```

该检查使用只读连接。外部服务可用性、图片呈现和完整角色操作需在配置实际依赖后验证。

## 功能验收

1. 上传公共图片并审核，查看压缩图、缩略图与元信息。
2. 在个人/团队空间管理图片，对比 viewer、editor、admin 的操作权限。
3. 选择主色搜索，核对排序与最低相似度。
4. 多选图片修改分类、标签和命名规则，测试旧版本及混入其他空间图片。
5. 在详情页复制分享链接、扫描二维码，分别测试公开与空间图片访问。
6. 在两个浏览器连接中尝试争取编辑权、保存与断线恢复。
7. 查看六类空间分析，核对统计范围与空数据。
