# 能力边界与路线图

当前会话、房间和锁为单 JVM；公有读图片直链不因空间鉴权变私有；密码保留原型 MD5 兼容，需带迁移的升级；协作不是多人像素编辑；AI 默认关闭且费用/私有空间回填策略待完善。前端 bundle 可能偏大，不宣传未测出的首屏提升。

生产前依次完善：

1. 文件隐私与历史链接治理。
2. 密码迁移、登录限流、CSRF、Cookie 安全、精确 CORS 与 HTTPS。
3. 云费用、AI 预算及清理失败任务告警。
4. 审计、监控、备份恢复与依赖安全检查。
5. 多实例会话、租约/围栏与广播一致性。
6. 可追溯数据集、冷/热缓存对照、P95/P99、命中率和错误率。

统计分析、动态分表、Disruptor、以图搜图与完整分享/邀请生命周期仍是扩展目标，不因原型 README 列出就认定已实现。
