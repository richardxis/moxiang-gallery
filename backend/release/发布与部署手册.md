# 发布与部署手册

本目录脚本用于构建产物审查与本地演示启动。详尽配置见 [安装说明](../../docs/SETUP.md)，公开版部署限制见 [路线图](../../docs/LIMITATIONS.md)。

```powershell
mvn '-Dtest=*BoundaryTest' package
powershell -NoProfile -ExecutionPolicy Bypass -File .\release\check-release.ps1 -ForPublication -FrontendRoot '..\frontend'
powershell -NoProfile -ExecutionPolicy Bypass -File .\release\start-local.ps1 -ConfigFile '自己的完整路径\application-local.yml'
```

没有 Git 仓库、只检查本地 JAR 时可单独使用 -SkipGitIndex；这不能代替发布检查。ForPublication 不允许跳过索引。

启动脚本绑定回环地址，关闭 AI 和 SQL 参数日志；不执行数据库迁移，不创建账号或改桶。自定义 java/JAR/配置路径使用对应参数；端口占用时报错，不结束其他服务。

在 Linux 可直接使用 java -jar，并显式指定自己的外部配置：

```sh
java -jar target/moxiang-picture-backend-0.0.1-SNAPSHOT.jar \
  --spring.profiles.active=local \
  --spring.config.additional-location=file:/your/private/application-local.yml \
  --server.address=127.0.0.1 \
  --picture.ai.enabled=false \
  --mybatis-plus.configuration.log-impl=org.apache.ibatis.logging.nologging.NoLoggingImpl
```

这是运行方法示例，Linux 脚本链路未在本轮验证。正式部署还需 TLS、Cookie/CSRF、私有对象读取、限流、审计、备份恢复等门禁，不能只开放 8123 端口就认定上线完成。
