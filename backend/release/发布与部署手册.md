# 发布与部署

## 构建

```powershell
cd backend
mvn '-Dtest=*BoundaryTest' package
powershell -NoProfile -ExecutionPolicy Bypass -File .\release\check-release.ps1 -SkipGitIndex
cd ../frontend
npm ci
npm run build
```

后端使用可执行 JAR，前端使用 dist 静态文件。运行配置与凭据通过外部文件或环境变量提供。

## 启动

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\release\start-local.ps1 -ConfigFile '.\config\application-local.yml'
```

脚本默认监听回环地址 8123。Linux 服务可使用进程管理器运行 Java，并通过 Spring 的外部配置机制设置同样参数。

## 反向代理

- 前端静态资源与 history 路由回退。
- /api 转发至后端，保留 Cookie 与正确的主机信息。
- WebSocket 转发 Upgrade 和 Connection 头，设置适当空闲超时。
- 使用 HTTPS，并配置前端 Origin、Cookie 和对象存储访问策略。

## 发布检查

确认数据库字段、配置、健康检查、日志、备份与回滚版本。数据库变更按迁移顺序执行。文件操作与模型任务分别观测失败、重试和费用。

仓库提交前可运行 `check-release.ps1 -ForPublication -FrontendRoot '..\frontend'` 检查发布索引。JAR 检查排除私有 profile、环境文件与私钥资源。
